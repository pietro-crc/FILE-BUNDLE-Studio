A preflight capability is not a conversion-completion claim. A family becomes production-converted only after its adapter has fixtures, per-file failure handling, security limits, and output tests recorded here.


## STEP-009 security overlay

Secret handling is an overlay on supported semantic extraction, not a new format capability level. Text/code, CSV/TSV, XLSX/XLSM, PDF, DOCX/DOCM, PPTX/PPTM, and image metadata pass through the bounded scanner after extraction. Report-only preserves derived content; redact changes derived text only; exclude removes the file from derived outputs. Visual PDF/image/Office/spreadsheet assets are omitted when content redaction has occurred and reliable visual redaction is unavailable. Unsupported binary formats remain inventory-only and are not falsely declared scanned.
