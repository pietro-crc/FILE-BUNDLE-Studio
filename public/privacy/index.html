Privacy by design

Your source files stay in your browser.

AI Bundle Studio is designed to convert selected files locally. The application does not require an account or send source-file contents to an AI Bundle Studio conversion server.

Open the local converterRead the details

What local processing means

When you select a ZIP, folder, or group of files, the browser grants the page access only to the items you chose. AI Bundle Studio reads those items through browser APIs, creates a temporary virtual file system in memory, and generates the Markdown, PDF, and JSON outputs on your device.

The source content is not submitted to a remote conversion API. Refreshing or closing the page ends the active session and clears the in-memory project state. Downloaded output files remain wherever you save them on your device.

What the site may receive

The web host necessarily receives ordinary network information required to deliver the site, such as an IP address, requested URL, timestamp, and browser request headers. The site also uses Cloudflare Web Analytics to understand aggregate performance and page usage.

Analytics may process limited technical information about page visits and device or browser characteristics. It is separate from the local conversion workspace and is not used to transmit the names or contents of the files you select.

What AI Bundle Studio does not need

  • No user account is required for local conversion.
  • No source ZIP, folder, document, or code file is uploaded to an AI Bundle Studio conversion backend.
  • No API key or AI-provider credential is required.
  • No generated bundle is automatically sent to an AI assistant.
  • No active project is intentionally retained by the application after the page is closed or refreshed.

Your responsibilities

Only process files you are authorized to use. Review the source for credentials, personal data, confidential client information, regulated data, and third-party material before conversion. Although processing is local, sensitive information can still appear in the generated outputs.

Uploading comes later: if you attach the generated files to an external AI service, that service's privacy policy, retention rules, and account settings apply. AI Bundle Studio does not control that later upload.

Security boundaries

Browser-only processing reduces data transfer, but it does not guarantee that every device, browser extension, downloaded file, or destination service is secure. Keep your browser updated, use a trusted device, inspect the generated outputs, and avoid processing secrets unless necessary.
